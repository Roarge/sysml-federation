{%- comment -%} The share links under an article. Each is a plain link to the service's own page for sharing, so nothing from LinkedIn, Bluesky or X loads until a reader follows one. The article layout passes the title and standfirst as plain text, and the page's full address. url_encode writes a space as "+". The intents read that as a space, but a mail program shows a plus sign, so every "+" left after encoding, which can only have been a space, becomes %20. A line break in a mailto body is %0D%0A. LinkedIn takes the address alone and reads the title and picture from the page's Open Graph tags. Bluesky takes one text. X takes the text and the address apart. Copy link needs site.js, so its item stays hidden until the script shows it. {%- endcomment -%} {%- assign share_q_url = include.url | url_encode | replace: '+', '%20' -%} {%- assign share_q_title = include.title | url_encode | replace: '+', '%20' -%} {%- assign share_q_dek = include.dek | url_encode | replace: '+', '%20' -%}
